# The HookLink branch of nxnative

This branch is the build engine of [HookLink](https://github.com/dsi-hub/HookLink), a Mac app that builds *The Legend of Zelda: Ocarina of Time* (Nintendo Switch 2 Edition) for iPhone from the player's own dump. It is [nxnative](https://github.com/seedds/nxnative) (MIT) plus the changes below, made and tested for this game on an iPhone 18 Pro Max (A20 Pro, iOS 27.2). HookLink downloads this branch and keeps it up to date.

No game files, keys or anything built from a dump are here. The pipeline rows in `dm/games/0400486024DEC000/pso_manifest.tsv` are shader identifiers and drawing settings, the same kind of list nxnative ships.

## Changes over nxnative

- **Pipelines:** a hybrid draw remembers pipelines the archive had no base for, instead of searching every archive file on each draw of each frame. Demanded builds get at least 3 queues, and their table is indexed by key. Each pipeline a draw stands in for goes into `pso_user.tsv` when first asked for, so the next start's prepare step builds it (`DM_PSO_DEMAND_RECORD=0`: only once built). `DM_PSO_BG_QUEUES` and `DM_PSO_BG_QOS` tune the background builds.
- **Prewarm list:** Ocarina's list takes the rows recorded on the iPhone in Kokiri Forest, Hyrule Field, Castle Town and Hyrule Castle, plus one mesh pipeline nxnative's seed rows lacked.
- **Memory:** shared textures no live object uses are retired under memory pressure, fixing the freeze after the talk with Saria (PR #1455). Render targets use nxnative's own recycling (7f502220); the earlier shared placement heap (PR #1453) is gone, as nxnative found it can corrupt the picture. An iPhone gets an 8 GB alias region and no map limit (`mem_alias`, `mem_map_limit` in Ocarina's profile): with 4 GB the game ran out of addresses when the Master Sword is pulled and stayed on a white screen.
- **Game speed:** Ocarina's frame ratio is never below the measured frame time (from PR #1543, after gunvalk's finding in Lichii PR #216), so the game keeps real speed below 60 fps with `DM_FPS_HOLD off`. The frame time floor is not paid back twice by the host's debt (`nvn_fstep_moved`), and the host can ask the game for its half rate under a hold (`DM_FPS_HALF_RATE=1`, off by default); both from oliverames.
- **Frame pacing on iOS:** the thread that presents the game's frames runs user-interactive whatever its priority. Under `DM_QOS_MAP` it was user-initiated, and iOS kept it on the efficiency cores (1.6 GHz instead of 3.7), so Hyrule Field fell to 41-55 fps with the GPU half idle (`DM_FRAME_QOS=0` turns it off).
- **Touch controls:** a Glass colour theme on every layout, and a Mobile layout (floating stick, camera on the right half, glass keys, a D-pad), inspired by cheemu21's kid-with-sword, from the kid-with-sword fork.
- **Wide view (experimental):** a launcher setting that makes the output and render sizes follow a screen wider than 16:9 at each start (`DM_WIDE_VIEW`), from nxnative PR #1460's sites. In handheld mode the game's cameras keep 16:9, so the game cameras' own aspect is scaled by the picture's ratio over 16:9 where they set it (main+0x4c533c, +0x2e1bb6c, +0x2e1c7d0), and other 16:9 aspects take the picture's ratio. The HUD and menus are still stretched, and the wider view costs GPU time.
- **Submission:** up to 32 command allocators in flight (`DM_NVN_ALLOC_CAP`); side-by-side compute dispatches (`DM_NVN_DISPATCH_OVERLAP`) and lossy render targets (`DM_NVN_RT_LOSSY`) are off by default.
- **Frame rate mode (`DM_FRAME_MODE`):** one launcher choice for 60 fps, 30 fps steady, 30 fps + frame generation (default) and 60 fps + frame generation on a 120 Hz screen; frame generation (MetalFX frame interpolation) and the steady 30 come from cheemu21's kid-with-sword-remake (V17, X2-X9), merged onto nxnative's present path. MetalFX is the default upscaler.
- **Memory cutoff:** with no map limit, MapPhysicalMemory is refused past `DM_MEM_CUTOFF_MB` (10240) or, on iOS, with less than `DM_MEM_ROOM_MIN_MB` (768) left to the limit, so the SDK frees its cached pages instead of iOS closing the game.
- **Present deadline (`DM_RT_PRESENT`):** the thread that presents declares its own frame deadline when another thread acquires, so iOS does not keep it on the efficiency cores.
- **Launcher:** Settings / Play / Extras on iOS and the Mac. Extras exports saves and the game log, imports a save (with a backup), holds cloud saves, cheat files (`Documents/cheats`), Reset to tested defaults and the credits. A touch controls opacity slider (`DM_PAD_OPACITY`); the Mobile layout takes the Classic and Forest themes' flat keys.
- **Wide view's HUD:** the game lays its screen out at the render width in handheld mode (main+0xe8303c, `DM_WIDE_VIEW_SIZE`), and a 16:9 camera aspect is scaled only once.
- **iOS:** `Documents/res_overlay` is read as a game file overlay (HookLink's resolution file). Ocarina gets a pipeline archive for `g19p`.
